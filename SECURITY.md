# Security

## Supported versions

Fixes go into `main` and ship in the next App Store and TestFlight build. Only the current App Store release is supported.

## Reporting a vulnerability

Report it privately through GitHub's form: [Report a vulnerability](https://github.com/inceptyon-labs/siren/security/advisories/new). Don't open a public issue.

Include what an attacker can do, the steps to reproduce, and the device and Siren version. Leave out your server address and tokens; we'll ask if they're needed.

Problems in Audiobookshelf itself go to the Audiobookshelf project.

## What to expect

A reply within a few days, an estimate once the problem is confirmed, and credit in the release notes if you want it.
